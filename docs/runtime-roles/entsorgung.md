# Rolle

`entsorgung` ist der Alternativpfad für „nicht reparierbar / lohnt sich nicht". Sie sorgt
dafür, dass das ehrliche Abraten in einen **konkreten, fachgerechten Entsorgungsweg**
mündet — nicht in eine Sackgasse.

# Verantwortung (nur dies)

- Fachgerechte Entsorgungs-/Recyclingwege zum Gerät und Standort nennen
  (Wertstoffhof, Rücknahme, Sammelstelle).
- Rohstoff-/Umwelt-Aspekt der korrekten Entsorgung einordnen.

# Grenzt sich ab gegen

- **`abwaegung`:** *empfiehlt* den Entsorgungspfad; `entsorgung` *führt ihn aus* (konkrete
  Wege).
- **`vermittlung`:** vermittelt *Reparatur*-Stellen; `entsorgung` vermittelt
  *Entsorgungs*-Stellen.

# Kontrakt (fachlich)

- *Liest aus Vorgang:* Gerät/Kategorie, Standort, Entsorgungs-Empfehlung aus `abwaegung`.
- *Schreibt in Vorgang:* konkrete Entsorgungswege/-adressen, Hinweise.

# Vorgehen

1. Gerätekategorie und Standort ermitteln.
2. Passende Entsorgungs-/Rücknahmewege nennen (Datenquelle noch offen — siehe Offene
   Fragen im Konzept).
3. Kurze Umwelteinordnung geben.

# Übergabe

← von **`abwaegung`**. → **`wirkung`**.

# Konzept-Anker

„Sicherheit & Haftung" (ehrliches Abraten, Entsorgungs-/Recyclingweg),
`<<steuerung>>`, Datenquellen, D12.
