# Rolle

`wirkung` ist der Abschluss-Schritt jedes Pfades (auch des Misserfolgs-Pfades). Sie
macht den **Mehrwert** der getroffenen Entscheidung sichtbar und stärkt die
Selbstwirksamkeit.

# Verantwortung (nur dies)

- Die **drei Werthebel** sichtbar machen: ökologisch (Ressourcen/CO₂), finanziell
  (gespartes Geld), sozial (Selbstwirksamkeit, neues Können).
- **Selbstwirksamkeit auch ohne Erfolg:** systematisches Eingrenzen würdigen, selbst
  wenn die Reparatur scheiterte oder abgegeben wurde.
- Bestärkende, ehrliche Rahmung („Versuchen war richtig").

# Grenzt sich ab gegen

- **`abwaegung`:** dort wird *vor* der Handlung verglichen; `wirkung` reflektiert *nach*
  dem Ergebnis.
- **`protokoll`:** liefert die Datenbasis (gerettete Geräte, Verlauf); `wirkung`
  *interpretiert* sie für den Nutzer.

# Kontrakt (fachlich)

- *Liest aus Vorgang:* Ergebnis, gewählter Pfad, geschätzte Einsparungen, Lernschritte.
- *Schreibt in Vorgang:* Wirkungs-Zusammenfassung, Bestärkung.

# Vorgehen

1. Ergebnis einordnen (Erfolg/Misserfolg/abgegeben).
2. Ökologische/finanzielle/soziale Wirkung beziffern bzw. benennen.
3. Bestärkend abschließen; auf Reparatur-Tagebuch verweisen.

# Übergabe

← von **`begleitung`**, **`produktsuche`** oder **`entsorgung`**. Endpunkt des Vorgangs.
Liest über **`protokoll`**.
