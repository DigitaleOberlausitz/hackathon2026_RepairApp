# Rolle

`bewertung` ist das Herzstück: die **Warn-Ampel**. Sie bündelt mehrere Achsen zu einer
verständlichen Einschätzung pro Gerät + Defekt und ist der Entscheidungs-Knotenpunkt.
Grundhaltung: **warnen statt sperren** — der mündige Nutzer entscheidet.

# Verantwortung (nur dies)

- Einstufung der vier Achsen: **Sicherheit (Risiko)**, **Komplexität (Aufwand)**,
  **Kostenaufwand**, **Machbarkeit** (Ersatzteile/Reparierbarkeit).
- Daraus die Handlungsempfehlung ableiten: *selbst machen · Repair Café · Profi ·
  fachgerecht entsorgen*.
- **Haftungshinweis (D16)** und Warnung skalierend mit der Kritikalität; **Vertrauens-
  Indikator (D3)**.

# Grenzt sich ab gegen

- **`abwaegung`:** `bewertung` liefert ein **grobes Machbarkeits-/Risiko-Gate** (ist
  Reparatur überhaupt sinnvoll/sicher?). Den *detaillierten Pfadvergleich* (Kosten,
  Zeit, Ökologie, Förderung) macht `abwaegung`. Die Kostenaufwand-Achse hier ist nur
  die grobe „lohnt es sich gegenüber Neukauf"-Ampel, keine Kostenrechnung.

# Kontrakt (fachlich)

- *Liest aus Vorgang:* Ursachen-Kandidaten, Gerät/Modell; Belege aus `recherche`.
- *Schreibt in Vorgang:* Ampel-Einstufung (4 Achsen), Handlungsempfehlung, Warnstufe.

# Vorgehen

1. Pro Achse einstufen (🟢/🟡/🔴), bevorzugt belegt über `recherche`.
2. Empfehlung ableiten; bei Rot deutlich abraten, ohne Schicht B hart zu sperren (D15).
3. Haftungs-/Sicherheitshinweis ausgeben, Konfidenz/Begründung mitführen.

# Übergabe

← von **`diagnose`**. → **`abwaegung`**. Bei Profi/Café-Empfehlung nutzt sie
**`vermittlung`**. Nutzt **`recherche`**.

# Konzept-Anker

`<<warn-ampel>>`, D1, D15, D16, D3.
