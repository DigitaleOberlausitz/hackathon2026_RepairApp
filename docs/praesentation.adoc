// =====================  FOLIE 3 — Aufzählung  ================================
<<<
== Das Problem

* Geräte werden zu früh weggeworfen — oft wäre eine Reparatur möglich.
* Nutzer fehlt das Wissen: *Was ist kaputt? Lohnt sich die Reparatur?*
* Hürden: Ersatzteile finden, Werkstatt finden, Fördermittel kennen.
* Folge: unnötiger Elektroschrott, vermeidbare Kosten.


// =====================  FOLIE 4 — Zwei Spalten  ==============================
<<<
== Reparatur vs. Neukauf

[cols="1a,1a", frame=none, grid=none]
|===
|
.Reparatur 🟢
* Ressourcen schonen
* meist günstiger
* Selbstwirksamkeit stärken
* Fördermittel möglich

|
.Neukauf 🔴
* Neueinrichtung & Einlernen
* Transport & Entsorgung
* höhere Kosten
* Ausfallzeit
|===


// =====================  FOLIE 5 — Drei Werthebel  ===========================
<<<
== Drei Werthebel

[cols="1,3", frame=none, grid=rows]
|===
| 🌱 *Ökologisch* | Reparatur als nachhaltige Alternative sichtbar machen.
| 💶 *Finanziell* | Den echten Mehrwert gegenüber dem Neukauf aufzeigen.
| 🤝 *Sozial*     | Selbstwirksamkeit fördern — sich mehr zutrauen.
|===
